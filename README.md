# --== КВАНТОВЫЙ ГЕНЕРАТОР "АВРОРА" v4.20 BLAZING RETRO EDITION ==--

Это веб-приложение — результат эволюции и творческого поиска, объединяющий передовые технологии в оболочке ностальгического Web 1.0. Проект сочетает истинную случайность квантовых вычислений для генерации идей и мощь нейросети GigaChat для их визуализации.

Интерфейс выполнен в стиле "хакерского терминала" из 90-х, создавая уникальный пользовательский опыт.

## Ключевые Концепции

- **Квантовый Оракул:** В основе генерации идей лежит симулятор квантового компьютера. Он создает уникальную битовую последовательность ("квантовый хэш"), которая используется как "ДНК" для процедурной генерации сложных и непредсказуемых текстовых промптов.
- **Нейросетевая Визуализация:** Все промпты обрабатываются нейросетью GigaChat для создания изображений.
- **Кибер-Ретро Эстетика:** Весь интерфейс — это оммаж эпохе Web 1.0 (1996-1999), с характерными элементами дизайна и звуковым сопровождением.

## Возможности

- ### Режимы Генерации:
    - **АРТ-ОРАКУЛ:** Создание сложного промпта на тему эпического и фэнтезийного искусства.
    - **МЕМ-ОРАКУЛ:** Создание промпта на абсурдную или смешную тему.
    - **КОТ-ОРАКУЛ:** Создание промпта, посвященного котикам.
    - **РАССКАЗЧИК:** Генерация промпта, по которому GigaChat создает и картинку, и короткую историю.
    - **РУЧНОЙ_ВВОД:** Позволяет пользователю ввести свой собственный текстовый промпт.

- ### Пользовательский Опыт:
    - **"Hacker Terminal" UI:** Интерфейс в виде ЭЛТ-монитора с черным фоном и зеленым текстом.
    - **Анимация "загрузки":** Элементы интерфейса появляются последовательно, имитируя загрузку старой ОС.
    - **Звук модема:** При загрузке страницы синтезируется и проигрывается звук Dial-Up подключения.
    - **Интерактивность:** Кнопка "[ ОТБОЙ ]" проигрывает гудки и перезагружает "соединение".
    - **Аутентичные элементы 90-х:** Бегущая строка, счетчик посетителей, гостевая книга, веб-ринг.

- ### Дополнительные Функции:
    - **Квантовый Сертификат:** Для каждого "квантового" произведения можно сгенерировать уникальный сертификат подлинности.
    - **Скачивание и Просмотр:** Любое сгенерированное изображение можно скачать или открыть в полном размере.

## 🚀 Развертывание на Hugging Face Spaces

Этот проект идеально подходит для развертывания на **Hugging Face Spaces**.

1.  **Загрузите проект на GitHub:** Убедитесь, что все файлы, включая `Dockerfile`, `requirements.txt` и этот `README.md`, загружены в ваш репозиторий `https://github.com/coolmag/quantumARt`.

2.  **Создайте "Space" на Hugging Face:**
    - Зайдите на [huggingface.co](https://huggingface.co/) под своим аккаунтом.
    - Нажмите на свой профиль и выберите **"New Space"**.
    - **Space name:** Придумайте имя (например, `quantum-aurora`).
    - **License:** `mit`.
    - **Space SDK:** Выберите **Docker**.
    - **Space hardware:** `CPU basic - FREE`.
    - Нажмите **"Create Space"**.

3.  **Подключите GitHub-репозиторий:**
    - На странице вашего нового "Space" перейдите во вкладку **"Files and versions"**.
    - Следуйте инструкциям, чтобы подключить ваш репозиторий `https://github.com/coolmag/quantumARt`.

4.  **Добавьте секретный ключ:**
    - На странице вашего "Space" перейдите в **"Settings"**.
    - Прокрутите до раздела **"Repository secrets"**.
    - Нажмите **"New secret"**.
    - **Name:** `GIGACHAT_AUTHORIZATION_KEY`
    - **Secret value:** Вставьте сюда ваш длинный ключ авторизации от GigaChat.
    - Нажмите **"Add secret"**.

5.  **Запустите сборку:** Hugging Face автоматически начнет "собирать" ваш проект с помощью `Dockerfile` и развернет его. Через несколько минут ваш "Терминал Аврора" будет доступен в интернете по адресу `ВАШ_НИКНЕЙМ-ИМЯ_СПЕЙСА.hf.space`.

## Локальный запуск (для тестов)

1.  Создайте виртуальное окружение: `python -m venv .venv` и активируйте его.
2.  Установите зависимости: `pip install -r requirements.txt`.
3.  Создайте файл `.env` и добавьте в него `GIGACHAT_AUTHORIZATION_KEY="ВАШ_КЛЮЧ"`.
4.  Запустите сервер: `python app.py`.
5.  Откройте в браузере: `http://127.0.0.1:5000`.
